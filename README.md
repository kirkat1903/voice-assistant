# Айко — голосовой помощник для Windows

Локальный голосовой ассистент: слушает микрофон, понимает русский и английский,
выполняет команды и отвечает живым голосом. Работает в фоне через иконку в трее,
показывает виджет с индикатором громкости, умеет запускаться вместе с Windows.

Помощник откликается на имя **«Айко»**: вслух он говорит только тогда, когда его позвали.
Команды без имени выполняются молча (результат виден в виджете), а опасные —
выключение, перезагрузка, сон, блокировка, закрытие программ — только после «Айко, …».

## Возможности

- **Голос** — нейронный голос Microsoft (`edge-tts`, Svetlana) с кэшем фраз на диске;
  без интернета автоматически переключается на системный голос (`pyttsx3`)
- **Распознавание речи** — Google Speech Recognition, русский + английский
- **Сайты и приложения** — по алиасам из `config.json` или поиском ярлыка
  в меню «Пуск» и на рабочем столе; «открой ярлык …»
- **Поиск** — «найди …»; «смени запрос на …» меняет поиск в текущей вкладке браузера
- **Окна и вкладки** — «закрой блокнот / окно / вкладку», «сверни/разверни окно»,
  «сверни все окна», «новая / следующая / предыдущая вкладка»; горячие клавиши отправляются
  кодами клавиш, поэтому работают и при русской раскладке
- **Утилиты** — время и дата, таймеры, напоминания, погода, курсы валют и крипты,
  громкость, яркость, медиаклавиши, скриншот
- **Виджет** поверх рабочего стола с кольцом громкости и полем правки поискового запроса
- **Сон** — «Айко, ложись спать»; разбудить можно, позвав по имени
- **Устойчивость** — повторные попытки, если микрофон ещё не готов после загрузки Windows
  или после сна; журнал ошибок в `assistant.log`

## Установка

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Для Python 3.14 у `pyaudio` пока нет готового wheel — используйте Python 3.11–3.13.

## Запуск

```bash
python voice_assistant.py     # в консоли
python tray_app.py            # в трее + виджет
python install_autostart.py   # добавить в автозагрузку (remove — убрать)
python make_icon.py           # перерисовать логотип (icon.png / icon.ico)
```

## Настройка

Всё задаётся в [`config.json`](config.json): кодовые слова (`wake_word`), город для погоды,
алиасы сайтов и приложений, системные команды, `widget_enabled`
и параметры голоса — `neural_voice`, `tts_voice`, `tts_rate`, `tts_pitch`.

## Примеры команд

«Айко, открой ютуб» · «найди рецепт борща» · «смени запрос на борщ с мясом» ·
«закрой вкладку» · «сверни окно» · «поставь таймер на 10 минут» ·
«напомни через час позвонить маме» · «погода в Москве» · «курс доллара» ·
«громче» · «сделай скриншот» · «ложись спать»
