# Айко — голосовой помощник для Windows

Локальный голосовой ассистент: слушает микрофон, понимает русский и английский,
выполняет команды и отвечает живым голосом. Работает в фоне через иконку в трее,
показывает виджет с индикатором громкости, умеет запускаться вместе с Windows.

Помощник откликается на имя **«Айко»**: вслух он говорит только тогда, когда его позвали.
Команды без имени выполняются молча (результат виден в виджете), а опасные —
выключение, перезагрузка, сон, блокировка, закрытие программ — только после «Айко, …».

## Возможности

- **Голос** — нейронный голос Microsoft (`edge-tts`, Svetlana) с кэшем фраз на диске;
  без интернета автоматически переключается на системный голос (`pyttsx3`)
- **Распознавание речи** — Google Speech Recognition, русский + английский
- **Сайты и приложения** — по алиасам из `config.json` или поиском ярлыка
  в меню «Пуск» и на рабочем столе; «открой ярлык …»
- **Поиск** — «найди …»; «смени запрос на …» меняет поиск в текущей вкладке браузера
- **Окна и вкладки** — «закрой блокнот / окно / вкладку», «сверни/разверни окно»,
  «сверни все окна», «новая / следующая / предыдущая вкладка»; горячие клавиши отправляются
  кодами клавиш, поэтому работают и при русской раскладке
- **Утилиты** — время и дата, таймеры, напоминания, погода, курсы валют и крипты,
  громкость, яркость, медиаклавиши, скриншот
- **Виджет-питомец** поверх рабочего стола (нативное окно Win32 с попиксельной прозрачностью):
  живой шар-«дух» реагирует на голос, речь, сон и команды; клик по нему — погладить;
  автоматически перезапускается треем, если упадёт
- **Сон** — «Айко, ложись спать»; разбудить можно, позвав по имени
- **Устойчивость** — повторные попытки, если микрофон ещё не готов после загрузки Windows
  или после сна; журнал ошибок в `assistant.log`

## Разговор по душам (друг и мини-психолог)

Айко умеет просто поговорить, поддержать и помочь разобраться в чувствах. Нужна языковая модель,
и есть бесплатные способы (`companion_provider` = `auto` сам выбирает первый доступный):

- **Groq** (бесплатный тариф, быстро, модель Qwen3 27B; если Groq её уберёт, Айко сама выберет другую доступную): ключ на <https://console.groq.com/keys>.
- **Google Gemini** (бесплатный тариф): ключ на <https://aistudio.google.com/apikey>. Внимание: на бесплатном
  тарифе Google может использовать данные для улучшения своих продуктов.
- **Ollama** (полностью на твоём ПК, без ключей и интернета): установи <https://ollama.com> и выполни
  `ollama pull qwen2.5:3b` — Айко найдёт её сама. На ноутбуке без видеокарты отвечает медленнее и проще.

Ключ сохраняется командой `venv\Scripts\python.exe set_api_key.py` (вводится скрыто, пишется только в
`secrets.json`, в git не попадает) или берётся из переменных окружения (`GROQ_API_KEY`, `GEMINI_API_KEY`,
`ANTHROPIC_API_KEY`). После этого перезапусти Айко (трей → «Перезапустить»).

Как это работает:
- «Айко, давай поговорим», «Айко, мне грустно», «Айко, как дела» — начинается разговор. Пока он идёт,
  имя повторять не нужно, Айко отвечает вслух на каждую фразу. Закончить: «хватит», «спасибо, пока»;
  через 5 минут тишины разговор закрывается сам.
- Любая непонятная фраза с именем тоже идёт в разговор, а команды («Айко, включи музыку») работают как обычно.
- «Айко, давай подышим» — голосовое дыхательное упражнение, работает и без ключа.
- «Айко, забудь наш разговор» — стирает историю (`chat_history.json`, хранится только на твоём ПК).
- При фразах о желании навредить себе Айко сразу тепло отвечает и подсказывает позвонить 112 или близкому человеку.
- Айко — ИИ, а не врач и не психолог; при долгих и тяжёлых состояниях она мягко посоветует обратиться к специалисту.

Настройки в `config.json`: `companion_model`, `companion_effort`, `companion_memory`,
`companion_enabled`, `user_name`.
Тексты разговора отправляются выбранному провайдеру — при Ollama остаются на ПК;
прокси Windows (VPN) учитывается автоматически.

## Лицо Айко — питомец Росток и Codex

С `"face": "sprout"` в `config.json` вместо шарика-виджета Айко показывается островком Sprout вверху экрана
(путь к exe — `sprout_exe`). Росток слушает, говорит, думает, спит и грустит вместе с Айко, её последняя фраза
видна в облачке. Росток работает поверх окон и показывает состояние задач Codex.

- Чат в Sprout (кнопка «Чат») идёт через Айко — бесплатно, на том же собеседнике и с той же историей, что и голос.
- Когда Codex ждёт ответа или заканчивает работу, Айко говорит это вслух.
- Голосом: «Айко, что делает Кодекс?», «Айко, какие задачи?», «Айко, разреши»,
  «Айко, отклони», «Айко, вариант два».
- В меню Ростка можно отключить микрофон Айко; при выходе из Ростка микрофон автоматически ставится на паузу.

Как это связано: Айко поднимает мост на `127.0.0.1` (случайный порт и токен в `%APPDATA%\Sprout\aiko.json`),
Sprout читает `state.json` и шлёт туда чат и события; команды Айко уходят в именованный канал Sprout.
Всё остаётся на этом компьютере. Код — `sprout_link.py`. Вернуть старый виджет: `"face": "widget"`.

## Установка

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Для Python 3.14 у `pyaudio` пока нет готового wheel — используйте Python 3.11–3.13.

## Запуск

```bash
python voice_assistant.py     # в консоли
python tray_app.py            # в трее + виджет
python install_autostart.py   # добавить в автозагрузку (remove — убрать)
python make_icon.py           # перерисовать логотип (icon.png / icon.ico)
python make_shortcut.py       # ярлык «Айко» на рабочем столе: запускает, а если уже работает — возвращает виджет
```

## Настройка

Всё задаётся в [`config.json`](config.json): кодовые слова (`wake_word`), город для погоды,
алиасы сайтов и приложений, системные команды, `widget_enabled`
и параметры голоса — `neural_voice`, `tts_voice`, `tts_rate`, `tts_pitch`.
