# Голосовой помощник

Локальный голосовой ассистент для Windows: слушает микрофон, распознаёт
русскую речь и выполняет команды — открывает сайты и приложения, ищет
в Google, управляет питанием ПК (блокировка, сон, перезагрузка/выключение).
Работает в фоне через иконку в системном трее, может добавляться в автозагрузку.

## Возможности

- Распознавание речи через Google Speech Recognition (`speech_recognition`)
- Голосовые ответы (TTS) с автоматическим выбором русского голоса (`pyttsx3`)
- Открытие сайтов по алиасам ("ютуб", "почту", "вконтакте" и т.д.)
- Запуск приложений по алиасам или поиском ярлыка в меню "Пуск"
- Поиск в Google по голосовому запросу
- Системные команды: блокировка экрана, сон, перезагрузка, выключение
- Иконка в трее с паузой/перезапуском/выходом (`tray_app.py`)
- Добавление в автозагрузку Windows (`install_autostart.py`)

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Для `pyaudio` на Windows при необходимости используйте готовый wheel
(`pip install pipwin && pipwin install pyaudio`).

## Настройка

Все алиасы сайтов/приложений, системные команды, язык распознавания и
кодовое слово задаются в [`config.json`](config.json).

## Запуск

```bash
python voice_assistant.py     # в консоли
python tray_app.py            # в трее
python install_autostart.py   # добавить в автозагрузку
```

Голосовые команды: «открой сайт …», «найди …», «открой …» / «запусти …»,
«заблокируй компьютер», «выключи ПК» и т.д. Для выхода скажите «выход» или «стоп».
